● One dataset do whole ladder: Fashion-MNIST. Same data, model get big. You see only model change, not data change. That how you learn.

  Ladder A — Fashion-MNIST (do all this in order)

  ┌─────┬─────────────────────────────────────────────────────────────────┬────────────────────────────────────────────────────┐
  │  #  │                              Model                              │                New thing you learn                 │
  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤

  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤

  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 5   │ Rewrite #4 in PyTorch nn.Module                                 │ autograd, optimizer, .backward()                   │
  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 6   │ Deep MLP (784→256→128→64→10)                                    │ vanishing gradient, weight init (He/Xavier)        │
  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤

  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤

  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 11  │ ResNet-lite (skip connection, 8-10 layer)                       │ residual, why deep net train now                   │
  ├─────┼─────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 12  │ Autoencoder (784→32→784)                                        │ unsupervised, latent space, reconstruction loss    │
